# 99 Shop Messenger Bot — সেটআপ গাইড (বাংলা)

এই সার্ভারটা Facebook Page-এর ইনবক্সে আসা মেসেজের উত্তর দেয়। কাস্টমার "লিপ লাইনার আছে?"
লিখলে দোকানের ক্যাটালগ থেকে খুঁজে দাম আর ছবিসহ উত্তর দেয়, আর অর্ডার নেয়।
ক্যাটালগ দোকানের নিজের সাইট (e99shop.com) থেকে সরাসরি আসে, তাই নতুন প্রোডাক্ট
আসলে বট নিজেই শিখে যায়।

## যা যা লাগবে

1. **GitHub অ্যাকাউন্ট** (ফ্রি) — কোড রাখার জন্য
2. **Render অ্যাকাউন্ট** (ফ্রি) — সার্ভার চালানোর জন্য
3. **Meta Developer অ্যাপ** (ফ্রি) — Facebook Page-এর সাথে যুক্ত করার জন্য

## ধাপ ১ — কোড GitHub-এ তোলা

1. github.com-এ গিয়ে নতুন repository বানান (নাম: `99shop-messenger-bot`, Public)
2. এই ফোল্ডারের সব ফাইল (`server.js`, `package.json`, `render.yaml`, `.env.example`)
   ওই repository-তে আপলোড করুন

## ধাপ ২ — Render-এ ফ্রি সার্ভার

1. render.com-এ অ্যাকাউন্ট খুলুন (GitHub দিয়ে লগইন করলেই হবে)
2. Dashboard → **New +** → **Blueprint** → GitHub repository-টা বেছে নিন
3. `render.yaml` দেখে `99shop-messenger-bot` নামে free web service বানাবে
4. সার্ভিসের **Environment**-এ এগুলো বসান:
   - `VERIFY_TOKEN` — নিজের বানানো একটা গোপন শব্দ (যেমন: `amar-gopon-token-123`)
   - `PAGE_ACCESS_TOKEN` — ধাপ ৩-এ পাওয়া Page token (আগে ফাঁকা রাখলেও চলবে)
   - `APP_SECRET` — Meta অ্যাপের App Secret (ধাপ ৩-এ পাবেন)
   - `ADMIN_TOKEN` — অর্ডার তালিকা দেখার পাসওয়ার্ড (নিজে বানান)
   - `DRY_RUN` — `0`
5. Deploy শেষ হলে সার্ভিসের ঠিকানা পাবেন, যেমন:
   `https://nine9shop-messenger-bot.onrender.com`
   এটা দিয়েই পরের ধাপ। প্রথমবার চালু হতে ১-২ মিনিট লাগে।

## ধাপ ৩ — Meta অ্যাপ আর Page সংযোগ

1. developers.facebook.com-এ গিয়ে **Create App** → **Other** → **Business** ধরনের অ্যাপ বানান
2. অ্যাপে **Messenger** প্রোডাক্ট যোগ করুন (Add Product)
3. **Settings → Basic** থেকে **App Secret** নিন → Render-এর `APP_SECRET`-এ বসান
4. Messenger → **Access Tokens** থেকে 99 Shop Page-এর **Page Access Token** নিন
   (Page-টা অ্যাপের সাথে যুক্ত করতে বললে অনুমতি দিন) → Render-এর
   `PAGE_ACCESS_TOKEN`-এ বসান
5. Messenger → **Webhooks**-এ **Add Callback URL**:
   - Callback URL: `https://<আপনার-render-ঠিকানা>/webhook`
   - Verify Token: Render-এ বসানো `VERIFY_TOKEN`-এর মান
   - **Verify and Save** চাপুন — ঠিক থাকলে সবুজ টিক আসবে
6. একই জায়গায় **messages** আর **messaging_postbacks**-এ সাবস্ক্রাইব করুন,
   আর Page-টা বেছে নিন

## ছবি দিয়ে খোঁজা (নতুন)

কাস্টমার ছবি বা স্ক্রিনশট পাঠালে বট ক্যাটালগের সাথে মিলিয়ে বলবে এটা আছে কি নাই:

1. ছবিটা পেয়ে AI (Google Gemini) দেখে বুঝবে এটা কী জিনিস
2. সেই বর্ণনা দিয়ে ক্যাটালগে খুঁজে কাছাকাছি ৫টা প্রোডাক্ট বের করবে
3. AI আবার ছবিগুলো মিলিয়ে সবচেয়ে কাছেরটা বেছে নেবে
4. মিলে গেলে দাম আর স্টকসহ দেখাবে; না মিললে কাছাকাছি ৩টা দেখাবে

চালু করতে `GEMINI_API_KEY` লাগে — এটা ফ্রি:

1. aistudio.google.com-এ যান (Google অ্যাকাউন্ট দিয়ে লগইন)
2. **Get API key** → **Create API key** চাপুন (ক্রেডিট কার্ড লাগে না)
3. চাবিটা কপি করে Render-এর Environment-এ `GEMINI_API_KEY`-এ বসান

ফ্রি চাবিতে মিনিটে ~১০-১৫টা ছবি, দিনে কয়েকশো পর্যন্ত চলে — দোকানের হিসাবে যথেষ্ট।
চাবি না থাকলেও বাকি সব চলবে; শুধু ছবি পাঠালে বট বলবে ছবি মেলানো এখনো চালু হয়নি।

মিলের মান: ওয়েবসাইট বা Facebook পোস্টের স্ক্রিনশট খুব ভালো মেলে (ছবিটাই এক)।
নিজের তোলা ছবি (অন্য অ্যাঙ্গেল/আলো) হলে মিল আনুমানিক — বট কাছের ২-৩টা দেখিয়ে
কনফার্ম করতে বলবে।

## ধাপ ৪ — পরীক্ষা

Page-এ গিয়ে মেসেজ করুন: "লিপ লাইনার আছে?" — বট দাম আর ছবিসহ উত্তর দেবে।
অর্ডার দেখতে: `https://<আপনার-render-ঠিকানা>/orders?token=<ADMIN_TOKEN>`

## জানা সীমা (ফ্রি প্ল্যান)

- Render ফ্রি সার্ভার ১৫ মিনিট মেসেজ না এলে ঘুমিয়ে যায়; তখন প্রথম উত্তরে
  ~১ মিনিট লাগতে পারে। বেশি কাস্টমার হলে ৭ ডলার/মাসের Starter প্ল্যান নিলে
  সবসময় চালু থাকবে।
- ফ্রি সার্ভারে অর্ডারের ফাইল সার্ভার রিস্টার্ট হলে মুছে যেতে পারে — তাই
  `/orders` পাতাটা নিয়মিত দেখুন। পরে ডাটাবেস যোগ করা যাবে।
- বট শুধু টেক্সট মেসেজের উত্তর দেয়; ভয়েস/ছবি মেসেজে "ফোনে জানান" বলে দেবে।
- শুরুতে **একটা Page**-এ চালু করুন (যেমন: 99 Shop Bangladesh)। ঠিকঠাক চললে
  বাকি Page-গুলোতেও একইভাবে যোগ করা যাবে।
